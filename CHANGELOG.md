# Changelog

User-facing changes are recorded here. Versions before 1.0 use patch bumps for
fixes and minor bumps for features or incompatible changes.

## [0.1.0] — 2026-10-05

### Added
- Initial Android 15+ release with live stream playback and ad-free routing.
- Channel browsing and search, Twitch sign-in, and live chat with emotes.
- Light and dark Material 3 interface.
- Signed APK and SHA-256 checksum distributed through GitHub Releases.

### Known limitations
- Early development; ad-free playback depends on available upstream sources.
